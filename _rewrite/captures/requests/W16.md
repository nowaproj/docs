# Capture requests: W16 (integrations: Firebase)

Section id used in image names: `integrations` (images go to `static/img/docs/integrations/<id>.png`).
Every Firebase screen after the first Google sign-in needs a Google account with a Firebase project (and, for the
Test sections, a database/device), so they are `needs-sign-in`. Use a throwaway Firebase project; never send a
notification to real users or write to a real database while capturing.
