## Product bugs

1. Variables list rename: in the name field of a new or renamed variable, param or function, t, r, v and f fire the board's tool keys (Text, Rect, Select tool, board focus), the rename ends and the old name stays (the tile then shows Globals and Details reads "Instance of 'minified:...'"); Ctrl+A selects all board items. Where: Variables panel, every screen and component. Steps: select the playground home screen, Variables, hover Variables, +, type `counter`. Details > Name works.
2. Group switch turns the screen gray: Stack to Column on the starter home screen paints it gray with "Canvas error: NoSuchMethodError: method not found: 'preferredSize'"; undo restores the Stack but the screen stays gray, and a widget dragged in afterwards lands loose on the board. Where: Details > Group, playground starter (extends P21 in `_rewrite/product-issues.md`, seen there as Column to Row in 3.12.5). Steps: click the home screen's title, Details > Group > down arrow.
3. Shift + drag drops the widget out of its screen: the axis lock works, but on release the widget becomes its own board item (Outline lists it next to HomePage, Layout shows X and Y). Where: board, a widget in a screen's Stack. Steps: drag a Container in the home screen with Shift held from the press, or pressed mid-drag. Plain and Alt drags are fine.
4. Bottom Navigation Bar set through the screen's slot isn't connected: Current Index stays 0, On Tap is empty, no `pageIndex` variable, and the status bar logs "Could not find index for navbar: TypeError ...". Where: Details > Screen > Bottom Navigation Bar slot. Steps: select the home screen, click the slot, pick Bottom Navigation Bar in "Search for a widget".
