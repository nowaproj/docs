# P9 forms review: Min length / Max length paragraph

Verifier check of the one paragraph after step 4 of `{#validators}` in `docs/reference/widgets/forms.md`. Code refs are in `/home/user/nowa-master` (v3.12.5), read only, nothing was run. Only that paragraph was edited.

## Result

The old paragraph was wrong in one place and incomplete in another. Rewritten to: "A **Min length** or **Max length** rule you add has no **Min** or **max** field in **Details**: right after you add it, it appears as a plain **Message** row, like **Required**. The length check stays in your code, and you change its number in code mode (see [Edit code in Nowa](../../code/code-mode.md)). Editing the **Message** is safe, but adding or removing another rule afterwards rewrites that row as a **Required** check and drops the length check, so add a length rule last."

## Not edited (outside the paragraph), for the page owner

1. Step 4 ("Change each rule's **Message**, and its **Min**, **max** or **Regex** setting") and the table cells "**Min** 6" / "**max** 40" say Min/max can be set in Details. They can't (see above). Suggested step 4: "Change each rule's **Message** and the **Regex** setting."
2. Step 3 says "Each rule can be added once." For Min and Max length that is not enforced: `options.remove(item.runtimeType)` (`form_validator.dart:49-51`) does not match a misread row, so the menu still offers both after you add one.
3. The **text validator** tile starts collapsed: `BFValidatorField` passes no `isOpen` to `CollapsibleTile` (`form_validator.dart:19-37`; default `false` at `block_field.dart:1162`; compare `class_field.dart:54`, which passes `isOpen: true`). After step 2 the rule list and **+ Add validator** show only once the arrow is clicked. Steps 2 and 3 don't say so. Worth a look in the playground.
4. `product-issues.md` P47 should say the misread is immediate (not "after reselecting") and that editing the row's **Message** is safe: the loss comes from adding or removing another rule.
5. Any validator code Nowa can't classify (extra statements, other conditions) is dropped or rewritten the same way when the rule list changes (`form_validator.dart:293-331`, `:342-346`). Not stated on the page.
