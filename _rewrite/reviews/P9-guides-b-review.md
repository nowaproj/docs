### Empty-list bullet (the question in the brief)

Code shows it works when the source returns a list. Kept, with two changes (list-only wording, **Expand** for the list inside the **Column**).

1. `createDataBuilderBlock` declares `data` as `dynamic` (`packages/core/lib/src/widgets_to_add/default_blocks.dart:231`, comment "type is infered"), but picking a source types it. `DataLinkMenu._onUpdate` sets `dataWidget.typeArgs = [innerType]`, the inner type of the function's `Future` or `Stream` (`packages/data/lib/src/common/data_link_menu.dart:41`). All three sources use it: `api_field.dart:73`, `sb_field.dart:43`, `firebase_field.dart:72`.
2. The `typeArgs` setter recomputes the constructor (`packages/core/lib/src/interpreter/block_tree.dart:5824-5828`). The class type with its arguments resolves `DataBuilder<T>.builder` (`Widget Function(BuildContext, T)`) to the real type (`packages/core/lib/src/interpreter/type.dart:414-420`, `member.dart:15-35,73-97`; `nowa_runtime_library.dart:123-175`), and a function expression's scope uses those inferred params (`block_tree.dart:6405-6425,6433-6455,6614`). The repo's own test proves it: `packages/data/test/data_test.dart:17-40` ("Passing a custom type to the data builder widget": `data` is declared `dynamic`, `typeArgs = [Axis]`, then `data` has type `Axis`).
3. In the link menu, clicking `data` while linking **Visible** (a `bool`) is a type mismatch, so the menu goes one level deeper (`packages/core/lib/src/fields/link_menu.dart:16,158`, `field_link_menu.dart:175-179`) and lists **Members** of `data`'s type: `type.allMembers`, supertypes included (`field_link_menu.dart:337`, `suggestion.dart:385-392,671-684`, `declaration.dart:339`, `type.dart:436-440`). `List` extends `Iterable` (`dart_core_library.dart:1201-1206`), and `Iterable` has `isEmpty` and `isNotEmpty` as `bool` (`dart_core_library_custom.dart:447-448`). The menu hides only void entries (`link_menu.dart:90-93`).
4. **Visibility** has **Visible** and **Replacement** (`packages/core/lib/src/fields/text_fields.dart:806-819`); linking a true/false value is on `logic/expressions.md#visibility`.
5. Limit: for a source typed `dynamic` (a request without a model returning raw JSON) `data` is `dynamic` and the member list has no `isEmpty`. The bullet now begins "When your source returns a list". A list inside a **Column** needs a bounded height, so the bullet adds "set the list's height to **Expand**" (`reference/widgets/lists.md`, checked by W13 against `packages/designer/lib/src/details/flex_size_field.dart:61-67`).
6. Not run in the app (no app access in this session). Evidence is the code path plus the repo test above.
