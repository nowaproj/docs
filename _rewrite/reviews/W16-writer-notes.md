**Product issue (important), confirmed by running `dart analyze`:** the **Google** provider writes `signInWithGoogle()` with the google_sign_in 6.x API (`GoogleSignIn().signIn()`, `googleAuth?.accessToken`; `fb_auth_blocks.dart:121-127`, template unchanged since 2024) while `connectGoogleAuth` adds `google_sign_in ^7.2.0` (`fb_auth_manager.dart:66`; the same `^7.2.0` is the supported-package version in `dart_package.dart` / `google_sign_in_package_config.dart:13`). In google_sign_in 7.2.0 the `GoogleSignIn` constructor is private, there is no `signIn()` and `GoogleSignInAuthentication` has no `accessToken`. A throw-away package with `google_sign_in: 7.2.0` and the same three lines reports three errors (`new_with_undefined_constructor_default`, `undefined_method` for `signIn`, `undefined_getter` for `accessToken`). Both branches of the `kIsWeb` check are compiled, so every platform build of a project with the Google provider on should fail. The page has a short `:::note` about it (easy to delete if the product team fixes it before release; dev `/home/user/nowa` still has the same template). Suggest adding it to `product-issues.md`.

Other assumptions: "everywhere else" for the `google_sign_in` branch follows the `kIsWeb` check in the template; the exact on-screen look of the **+** / check-mark tile control is taken from `auth_management_view.dart:109-158`.
