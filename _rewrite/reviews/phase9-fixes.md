### 1. List to detail recipe (review item 2)
- `docs/logic/navigation.md`: new H2 "Open a detail screen when a list item is tapped" (`{#open-a-detail-screen}`), between "Pass data to the next screen" and "Use the Navigator". Steps: make the item tappable (List Tile **On Tap**, or Gesture Detector / Ink Well wrapper), add a **GoRouter** node (`push`), **Location** `/product/` then `$` then `element`, then type `.id`; on the detail screen a **Data Builder** with **Source** Supabase and the **Get Record by ID** function, id input linked to the screen's param; **Play**. Closing paragraph says plainly: the path carries text, so GoRouter projects pass the id and refetch; **Extra** can carry a whole row but the Router panel can't map it to a screen param; in a Navigator project the whole row can be linked to the destination param. Also a component variant (id param, pick it after `$`) and a plain-sentence AI prompt (the page already has two admonitions).
  - `element` is a local declared in the item builder body (`final element = list[index]; return widget`): `packages/core/lib/src/widgets_to_add/default_blocks.dart:192-213`; created when a list is connected: `packages/core/lib/src/fields/list_view_field.dart:139-163`, `packages/core/lib/src/fields/grid_view_field.dart:41-62`.
  - An event's function is an inline closure (`FuncExpr.fromType`, button reads **+** or **Edit**): `packages/core/lib/src/fields/nowa_fields.dart:793-825`. It sits inside the item builder, so it sees `element` and `index`. Scope chain (`availableDeclarations` through every enclosing `ExecBlock` and `FuncExpr`): `packages/core/lib/src/interpreter/block_tree.dart:179, 2954-2957, 6330-6352, 6614`. The **LOCALS** category (shown upper-case) lists them: `packages/core/lib/src/interpreter/suggestion.dart:469-478, 588-634`. Link menus take the field's parent as scope: `packages/core/lib/src/fields/field_link_menu.dart:324-335`; the `$` menu takes the string block: `packages/core/lib/src/fields/interpolated_text_field.dart:89-103`.
  - `$` opens the menu (`packages/core/lib/src/fields/basic_fields.dart:100-117`) and inserts only the picked local as `{element}` (`interpolated_text_field.dart:68-73`); there is no member drill-down there (the next-page arrow is commented out, `packages/core/lib/src/fields/link_menu.dart:422-431`). Text inside `${...}` is parsed as an expression, so typing `.id` works: `packages/core/lib/src/interpreter/string_interpolation_parser.dart:70-84`.
  - GoRouter node starts as `push` with `/path`: `packages/core/lib/src/state_management/global_state_suggestions.dart:44-54`. Its **Location** and **Extra** fields come from the `push` parameters `location` and `extra` (`packages/core/lib/src/interpreter/libraries/go_router_library.dart:1447-1453`), labelled by `camelCaseToSpaces` (`packages/core/lib/src/fields/block_field.dart:213-219`, `packages/core/lib/src/utils.dart:77`) and listed by `packages/code/lib/src/customizations/go_router_field.dart:94-110`.
  - Router panel maps only path and query parameters (`state.pathParameters`, `state.uri.queryParameters`): `packages/core/lib/src/project/env_services/router_file_service.dart:890-1030`, `packages/core/lib/src/project/env_services/go_router_routing_service.dart:268-340`. Nothing reads `state.extra`, which is why the recipe passes the id.
  - Navigator whole-row route: **Navigator** node `to` field with the brush popup (`packages/code/lib/src/customizations/navigator_field.dart:68-110`, `packages/core/lib/src/fields/nowa_fields.dart:484-506`). The same link-menu scope offers `element`, and a type that matches links directly (`field_link_menu.dart:160-186`).
  - Component variant: public params of the widget class appear under **LOCALS** (`suggestion.dart:607-633`).
- One-line links to the recipe: `docs/reference/widgets/lists.md` (end of "Fill a list from your data"), `docs/integrations/show-data.md` (end of "Show a list"), `docs/integrations/supabase/database.md` (end of "Show the results in your app"), `docs/ai/prompting.md` (new row "Open a detail screen" in "Example prompts by task", **Agent**).
