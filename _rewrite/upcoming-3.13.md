# Upcoming in 3.13 (on `dev`, not released)

Changes on `nowaproj/nowa` `dev` that are not in the released v3.12.5. Pages listed here need an update
when 3.13 ships.

**How big is it.** `dev` is 54 commits ahead (25 Sep to 5 Oct 2026, including 5 merges and one change that was
reverted) and touches 450 files (+15.4k / -10.0k lines). `master`'s tree equals the merge base, so the tree diff is
exactly dev's work. Most of those files are a design-system pass (new buttons, list rows, trees and menus) that
restyles nearly every panel, dialog and menu without changing its labels: a diff of every string literal in the
changed Dart files found only the label changes listed below. The real UI change is in how you find, add and move
around in the editor: the **Library** panel replaces the Widgets panel (and, in the designer, the Files icon);
Cmd/Ctrl+K, Cmd/Ctrl+O and Cmd/Ctrl+B change meaning; the top bar gets **Back** / **Forward** and a searchable board
picker; the widget right-click menu renames its ordering entries and gains two shortcuts; and the files tree is
rebuilt. Smaller: `@Preview` widget variants, Git branch search, an enum "Default" option, local-project sync and
rendering fixes, and a Linux build that stays hidden. Expect the editor layout, Widgets panel, adding widgets, Files,
boards, keyboard shortcuts and context menu pages, and most editor screenshots, to need a pass. Code refs are to
`dev` (`/home/user/nowa`) unless marked `master:`.
