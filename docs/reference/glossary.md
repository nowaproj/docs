The words you'll see in Nowa, in plain language. Labels in **bold** are exactly what the app shows.

| Term | What it means |
|---|---|
| Agent mode | The Nowa AI mode that builds everything, from design to working features. Chip: **Agent**. See [Design, Plan and Agent modes](../ai/modes.md). |
| AI Assistant | The panel where you chat with Nowa AI. Open it with the **Assistant** icon in the sidebar. See [Chat with Nowa AI](../ai/chat.md). |
| AppState | The global state every new project starts with. See [Share data across your app](../logic/global-state.md). |
| Board | The design surface where your screens, components and widgets sit side by side. Switch boards from the board chip in the top bar. See [Work with boards](../design/boards.md). |
| Board item | A screen, component or loose widget placed on a board, with its own title bar (**Play**, **Open in new tab**). |
| Checkpoint | A saved point before a Nowa AI request. **Restore Checkpoint** undoes that request's changes; **Reapply Checkpoint** brings them back. See [Undo AI changes](../ai/undo-and-history.md). |
| Circuit | The visual logic editor, where a function is a chain of nodes. See [Build logic in Circuit](../logic/circuit.md). |
| Cloud project | A project stored in your Nowa account. Open it from any browser. See [Cloud and local projects](../get-started/cloud-and-local.md). |
| Code mode | The code editor over all your project files, opened with the `<>` button in the top bar. See [Edit code in Nowa](../code/code-mode.md). |
| Component | A reusable widget you build once and place anywhere. See [Build reusable components](../design/components.md). |
| Connector | A link that lets Nowa AI work in another service, such as Figma or Supabase. See [Connect Figma and Supabase](../ai/connectors.md). |
| Constants | Project-wide values and integration keys, in project settings. See [Keys and constants](../integrations/constants.md). |
| Deploy | The top-bar button that builds and publishes your app to the web, Android or iOS. See [Get ready to publish](../publish/index.md). |
| Design mode | The Nowa AI mode for the look and flow of your app, with demo data. Chip: **Design**. |
| Desktop app | Nowa for macOS and Windows. Needed for local projects and running on devices. See [Install the desktop app](../get-started/desktop-app.md). |
| Details panel | The panel on the right of the board that shows the selected item's properties. See [Change widget properties](../design/properties.md). |
| Event | A property like **On Pressed** or **On Tap** that starts your logic. See [Respond to taps and other events](../logic/events.md). |
| Global state | App-wide data and functions that any screen can use. See [Share data across your app](../logic/global-state.md). |
| Instant Play | Running a board item right on the board, instantly. The button says **Play**. See [Play your app on the board](../test/instant-play.md). |
| Local project | A project stored in a folder on your computer. Desktop app only. See [Work with local projects](../code/local-projects.md). |
| Model | A data class, such as a product or a user, that can be read from JSON. See [Data models](../logic/models.md). |
| Nowa AI | The AI agent built into Nowa. It designs, builds and fixes your app with you. See [How Nowa AI works](../ai/index.md). |
| Outline | The panel that shows the widget tree of the board or open screen. See [Use the Outline](../design/outline.md). |
| Parameter | A value a screen or component receives, such as the product to show. See [Pass data with parameters](../logic/parameters.md). |
| Plan mode | The Nowa AI mode that writes a plan you review before anything changes. Chip: **Plan**. |
| Playground | The editor you can use without an account, at `app.nowa.dev/playground`. See [Try Nowa without an account](../get-started/playground.md). |
| Public project | A cloud project anyone with the link can open and copy. See [Share your app](../test/share.md). |
| Run | Compiling and running the real app, in the editor or on a device. See [Run your app](../test/run.md). |
| Screen | A page of your app. See [Create and set up screens](../design/screens.md). |
| Session | One conversation with Nowa AI. Start one with **New Session**; reopen old ones in **Chat History**. |
| Share Preview | A link and QR code that let anyone try a screen in their browser. See [Share your app](../test/share.md). |
| Theme | Your app's colors, text styles and widget styles, edited in the **Themes** panel. See [Create and edit themes](../design/themes.md). |
| Thinking level | How long Nowa AI thinks before answering: **Instant**, **Thinking** or **Deep Thinking**. |
| Variable | A value your app remembers and can change, such as a counter. See [Store data in variables](../logic/variables.md). |
| Widget | A building block of your app, such as a text, a button or an image. See [Widget catalog](./widgets/index.md). |
| Widget picker | The searchable list of widgets you can add, opened with <kbd>Ctrl</kbd>/<kbd>⌘</kbd> + <kbd>K</kbd> or the toolbar's **Widget** tool. See [Add widgets](../design/add-widgets.md). |
| Widgets panel | The sidebar panel that lists your project's screens and components. Not the widget picker. |
| Workspace | A shared space for projects and team members. See [Workspaces and team members](../account/workspaces.md). |
| Wrapper | A widget that wraps another, such as Padding or Scroll View. See [Wrappers](./wrappers.md). |

## Renamed or removed

If you followed older tutorials, these names changed:

| You may have seen | Now |
|---|---|
| Think Mode | Thinking levels (**Instant**, **Thinking**, **Deep Thinking**) |
| New Chat | **New Session** |
| Replay (AI changes) | **Reapply Checkpoint** |
| Instant preview, Play mode | Instant Play (**Play**) |
| New Cloud Project | **New project** on the dashboard, or **What do you want to build?** |
| Assets panel | The **assets** folder in the **Files** panel |
