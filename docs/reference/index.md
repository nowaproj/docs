Some widgets need a little setup after you drop them on the board. These four guides walk you through them:

- [Lists and grids](./widgets/lists.md): repeat one item design for every entry in a list, such as every product in your shop.
- [Text fields and forms](./widgets/forms.md): add a text field and check what people type before you use it.
- [Navigation bars and screen parts](./widgets/navigation.md): add an app bar, a drawer, a floating button and a bottom navigation bar.
- [Images, video, animations and web content](./widgets/media.md): show pictures, video, animations and web pages.
