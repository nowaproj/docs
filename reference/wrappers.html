Wrappers

A wrapper goes around a widget and gives it one extra ability, while the widget itself stays as it is. Wrap a product card in a Gesture Detector and you can make it open the product page when tapped. Wrap a long column in a Scroll View and people can scroll through it. Nowa has 32 wrappers, and each one gets its own section in Details, so you set it up like any other widget.

Add a wrapper​

  1. Select the widget on the board or in the Outline.
  2. In Details, scroll to the bottom and click Add Wrapper. A search list opens with the hint Search for a wrapper.
  3. Type part of the name, such as pad or scroll, then click the wrapper or press Enter.
  4. Set it up in its new section, below the widget's own settings.

Add Wrapper shows only when exactly one widget is selected. Feel free to experiment: Ctrl/Cmd + Z takes a wrapper away again.

Width, height and position aren't in this list. You set them under Layout in Details, as described in Lay out widgets. The rest of Details is covered in Change widget properties.

Reorder wrappers​

Order changes the result, because each wrapper goes around everything above it. In Details, the widget's own section comes first, then its wrappers, starting with the one closest to the widget. A new wrapper goes around the ones you already have, so it lands at the bottom.

For example, say a widget has a Container wrapper and a Padding wrapper. With Padding below Container, the space sits outside the colored box, like a margin. Move Padding above it and the space sits inside the box, between its edge and the content.

To move a wrapper, hover over its section header and drag the grip icon (six dots) up or down. A colored line shows where it will land.

Remove a wrapper​

Hover over the wrapper's section header, click the ... button and choose Remove. Only the wrapper goes: the widget inside stays. Changed your mind? Ctrl/Cmd + Z undoes adding, moving or removing a wrapper.

The wrappers you'll use most​

These seven come up again and again. Each section says what the wrapper does, when to reach for it, and what its settings mean.

Padding​

Padding adds empty space around the widget, so its content doesn't touch the edges of the screen or its neighbors. A little space goes a long way: text is easier to read, related items look like they belong together, and buttons with room around them are easier to tap without hitting the wrong one.

  • It starts at 8 on every side. The first field sets the space on the left and right, the second the space on the top and bottom.
  • For a different value on each side, click Individual padding, the button next to the fields. You then get left, top, right and bottom. Click it again to go back to two fields.
  • Values can't go below 0.
  • On a Group, the first Padding shows in the Group's own Padding row instead of in a section of its own.

Where you put it matters: inside or outside a colored box gives a different look. See Reorder wrappers.

Scroll View​

Scroll View lets people scroll through a widget that's bigger than the space it has. Without it, whatever doesn't fit is cut off and nobody can reach it. That's a common surprise when content loaded from your data grows longer than the screen.

Use it for a long form, an article, a settings screen, or a row of cards that people swipe through sideways. Add it to the widget that holds the content, usually a Column, or a Row for sideways scrolling. Then hover the screen's title and click Play to scroll through it the way your users will.

SettingWhat it does
Scroll Directionvertical (the default) scrolls up and down, for a Column. Pick horizontal for a Row that scrolls sideways.
ReverseStarts at the bottom (or at the end, when scrolling sideways) instead of the top. Handy for a chat, where the newest messages sit at the bottom.
PaddingSpace between the edges of the scrolling area and the content.
PhysicsHow scrolling feels: BouncingScrollPhysics bounces back at the ends (iPhone style), ClampingScrollPhysics stops there (Android style), NeverScrollableScrollPhysics turns scrolling off and AlwaysScrollableScrollPhysics scrolls even when everything fits. Empty means each platform's usual feel.
Keyboard Dismiss BehaviorPick onDrag to hide the on-screen keyboard as soon as someone starts scrolling, which helps on a long form.

The other settings, such as Primary and Restoration Id, are for special cases, so you can leave them as they are. Inside a Scroll View, Expand isn't offered in the scrolling direction, because a scrolling area has no fixed end to fill. For a long list built from your data, a List View is often the better choice: it scrolls on its own and repeats one item design. For a row of tags that should continue on a new line instead of scrolling, see Scroll or wrap content.

Gesture Detector​

Gesture Detector makes any widget respond to touch, so a picture, a card or a line of text can work like a button. It has no look of its own: when someone taps, nothing changes on screen and your logic runs. If you'd like a ripple as feedback, use Ink Well instead.

EventRuns when someone...For example
On Taptaps onceopen a product page from its card
On Double Taptaps twice quicklylike a photo, or zoom into it
On Long Presspresses and holdsshow more options for an item
On Secondary Tapright-clicks with a mouseopen your own menu on the web or desktop

Click the + next to an event to create its logic. Circuit opens, and you add the steps that should happen. Afterwards the button reads Edit, so you can come back to it. Respond to taps and other events walks through an example.

Show advanced options lists many more events, such as a sideways swipe (On Horizontal Drag End) or a pinch (On Scale Update). On the board, a click selects the widget, so try your gestures with Play.

Visibility​

Visibility shows or hides a widget. Link it to a true or false value and your logic decides, so each screen shows only what matters right now: a sign-out button only when someone is signed in, an error message only when something went wrong, a "Your cart is empty" note only when it is.

  • Visible: on shows the widget, off hides it. A hidden widget takes up no space, so the widgets around it close the gap. Click the Visible label to link it to a variable or a condition.
  • Replacement: a widget to show in its place while it's hidden, such as a placeholder or a loading spinner. It's empty by default, so nothing shows.

For the full steps, including the logic that switches it, see Show or hide a widget.

Opacity​

Opacity makes a widget see-through. Set Opacity from 0 (invisible) to 1 (fully visible). It starts at 0.5, half see-through. Use it for a faded watermark or background picture, or a button that looks dimmed while it can't be used yet.

  • The value doesn't animate: a new value shows right away. To fade smoothly from one widget to another, use the Cross Fade widget.
  • At 0 the widget is invisible, but it still takes up its space and still reacts to taps. To remove something from view completely, use Visibility.
  • Screen readers, the spoken feedback that blind and low-vision people rely on, skip a widget at 0. Turn on Always Include Semantics if they should still read it out.

Material​

Material puts the widget on a surface with its own color and shadow, like a card lifted off the page. It's also the surface that Ink Well ripples are drawn on.

SettingWhat it does
ColorThe surface color. Leave it empty to use your theme's surface color.
ElevationHow high the surface floats. Above 0 it casts a shadow, and a higher number means a bigger shadow.
Shadow ColorThe color of that shadow.
Tint ColorA color laid over the surface. The higher the Elevation, the more it shows.
BorderAn outline, with Border Radius for rounded corners. Hover the Border header and click + to add one: it starts as a thin black line.
Border On ForegroundOn (the default) draws the border over the content. Off draws it behind.

No ripple when you tap an Ink Well? A filled widget, such as a Container with a color, covers it, because ripples are drawn on the Material surface underneath. Take the color off the widget, add a Material wrapper below the Ink Well in Details, and give the Material that color instead.

Text Direction​

Text Direction sets the reading direction for everything inside it. Pick rtl (right to left) for languages such as Arabic and Hebrew, or keep ltr (left to right), the default.

It does more than move text: rows inside it also lay out their widgets from right to left, so the first widget in a row moves to the right. Add it to a screen's main widget to set the direction for the whole screen. A single Text widget also has its own Text Direction setting. See Languages and right-to-left text.

All wrappers​

Every wrapper in the Add Wrapper list, with the name the list shows, grouped by what it does.

Space, size and position​

WrapperWhat it does
PaddingAdds empty space around the widget. See Padding.
AlignPlaces the widget inside the space it's given. It starts centered: move it with the Alignment sliders, for example to push a button into a corner of a card.
Constrained BoxSets the smallest and largest size the widget may take, with Constraints. Use it to stop a card from stretching too wide on a big screen.
Fractionally Sized BoxSizes the widget as a share of the space it's given, with Width Factor and Height Factor: 0.5 is half. Use it for a button that's always half as wide as the area it sits in.
Aspect RatioKeeps the widget at a fixed width-to-height ratio, whatever its width. It starts at 1, a square, and 2 is twice as wide as it is tall.
Fitted BoxScales the widget up or down to fit the space it's given, with Fit and Alignment. Use it to shrink a long title so it stays on one line.
Intrinsic HeightMakes the widget as tall as its content naturally is.
Intrinsic WidthMakes the widget as wide as its content naturally is.
Safe AreaKeeps the widget clear of notches, rounded corners and the phone's system bars. Choose the sides under Show advanced options. New screens already wrap their content in one.

Look and effects​

WrapperWhat it does
ContainerPuts the widget in a box with the same settings as the Container widget: fill, border, rounded corners, shadow, padding and margin. It starts with a gray fill. Use it to turn plain text into a colored tag. Its fill sits behind the widget it wraps, so it doesn't tint a picture. To tint one, use the Image's Color and Blendmode (see Add an image).
OpacityMakes the widget see-through, from 0 (invisible) to 1. See Opacity.
Clip radiusRounds the widget's corners and trims anything that sticks out. Set Border Radius. Use it for photos with rounded corners.
TransformRotates, scales or moves the widget without changing the space it takes. It starts with a rotation applied. Use it to tilt a sticker or a label.
Color FilterRecolors the widget by blending a Color over it with a Blend Mode.
MaterialA surface with its own color, shadow and border, where ripples show. See Material.
BadgeAdds a small badge to the corner of the widget, such as an unread count on a bell icon. It starts with the label "99".
AnimatedContainerA box that animates smoothly when its settings change, such as its color or size, like the AnimatedContainer widget. It starts with a 300 ms Duration and a gray fill.

Touch and motion​

WrapperWhat it does
Gesture DetectorMakes the widget respond to taps, double taps, long presses and more. See Gesture Detector.
Ink WellLike Gesture Detector, with a ripple when the widget is tapped. Set On Tap and the ripple colors, such as Splash Color. No ripple? See the tip under Material.
DismissibleLets people swipe the widget away, for example to delete an item from a list. On Dismissed runs when it's gone: remove the item from your list there, or your app shows an error when you try it with Run. Direction sets which way it swipes, and Background shows behind it as it slides.
Refresh IndicatorAdds pull-to-refresh: people pull down to reload, and On Refresh runs. It needs a scrolling widget inside, such as a List View or a Scroll View.
Interactive ViewerLets people pan and zoom the widget with their fingers. Use it for a floor plan or a photo people want to see up close.
TooltipShows a short hint when people hover over the widget with a mouse or long-press it. It starts with the message "Tooltip message". Use it to explain a button that only has an icon.

Show, hide and scroll​

WrapperWhat it does
VisibilityShows or hides the widget, switched by your logic. See Visibility.
Scroll ViewLets people scroll through content that's bigger than its space. See Scroll View.

Text and language​

WrapperWhat it does
Text DirectionLeft to right or right to left, for everything inside. See Text Direction.
Default Text StyleSets a starting text style, such as font, size and color, for every Text widget inside it. Settings a Text sets itself win. Use it to make all the text on a card one color in one go.

Data and logic​

WrapperWhat it does
Data BuilderLoads data, for example from an API or a database query, and hands it to the widget inside, with something to show while it loads and if it fails. See Show data in your UI.
Notifier BuilderRedraws only the widget inside it when a notifier you pick changes. A notifier is shared data that announces its changes, such as a global state. See Share data across your app.

Forms and screen parts​

WrapperWhat it does
FormGroups the text fields, dropdown menus and pin code fields inside it, so you can check them all at once, for example before sending a sign-up. Its section lists each field's validator: the rules a field's text must pass. Nowa also creates a formKey variable, which your logic uses to run the check. See Text fields and forms.
ScreenTurns the widget into a full screen, with slots for App Bar, Drawer, Floating Action Button and Bottom Navigation Bar.
DrawerTurns the widget into a drawer, the side menu that slides in over a screen, like the Drawer widget.
Or ask Nowa AI

Select a widget and ask in Agent mode, for example: "Make this column scrollable" or "Hide this button when the cart is empty." Then look in Details to see which wrapper it added and how it's set up.
